# BPK 408W final quiz guide

The whole course told as one story. Tap any dotted term for its definition.

## The one story {#story}

The whole term is one experiment: what happens if we overexpress myocardin in cultured muscle cells?

Myocardin is a protein that switches on smooth muscle genes. A7r5 cells are rat aortic smooth muscle cells that have drifted toward a flat, fibroblast-like, dividing state in culture. The course asks whether forcing them to make extra myocardin pushes them back toward a "real" contractile smooth muscle cell, the kind with organized actin cables and lots of contractile proteins.

Every technique you learned answers one piece of that question.

{{fig:pipeline|The term in one picture. Each box is a week's technique; each arrow is "this sets up the next readout."}}

You grow and count the cells (Week 1), learn to see them with fluorescent stains (Week 2), put the myocardin gene in with a plasmid (Weeks 3 and 4), pull out the RNA and copy it into cDNA (Week 5), stain the actin and image it (Week 6), then count the contractile-gene transcripts with ddPCR (Weeks 7 and 8).

There are two readouts at the end. One is structural: does the actin look more like a contractile cell? The other is molecular: did contractile gene mRNA go up? GFP tells you which cells got the plasmid in the first place.

## Threads that run through every week {#threads}

These ideas show up in almost every practice question. If you're stuck on a quiz question, one of these is usually the answer.

1. Controls tell you what "nothing happened" looks like. pEGFP cells (GFP but no myocardin), DM cells (no plasmid), the no-primer ddPCR well, and housekeeping genes are all controls. Each one removes a different alternative explanation.
2. Comparisons only work if everything else is equal. Same exposure settings for every image, same amount of RNA into every RT reaction, same threshold logic in every ddPCR well, same housekeeping gene for every condition.
3. Know where your molecule is. In the spin column the RNA is stuck to the silica until the very last step. In the microscope each fluorophore lives in one channel. In ddPCR each target molecule lives in one droplet.
4. Counting beats estimating. The hemocytometer counts cells in a known volume, ImageJ counts nuclei and GFP-positive cells, and ddPCR counts molecules directly. The course keeps choosing methods that turn "about how many?" into an actual number.
5. Each fluorescent color is a different molecule doing a different job. Blue is DNA (Hoechst), green is GFP (or WGA in Week 2), red is F-actin (phalloidin).
